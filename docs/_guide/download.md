---
title: Download Zap Fasterk
---

Download **Zap Fasterk** for Windows from the
[releases page](https://github.com/kevindevm/zap-fasterk/releases).

New releases carry Windows installers and portable builds with
`zap-fasterk` in their file names. The in-app updater moves between these
releases once you are on one of them; pick the installer or the portable
build, whichever you already use.

Version 0.30.0 and earlier live under
[eternalwaitt/zap-faster](https://github.com/eternalwaitt/zap-faster/releases).
Updates do not cross repositories, so an older installation will not update
itself into the new one. Install once from the new releases page instead,
then let the updater take it from there. Your chats, settings, and linked
session survive the move. Quit the old copy first: only one copy can run
against that data at a time.

Windows installers are not Authenticode signed. This platform signature is
separate from Zap Fasterk's signed update manifest.
